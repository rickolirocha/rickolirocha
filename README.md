## Uma decisão que resume minha abordagem

Em um teste do Plasma, identificamos que a atribuição de uma conversa a um atendente não impedia, de forma atômica, o envio de uma resposta pelo bot. Para aquela etapa, testamos uma alternativa mais simples: a IA prepara uma **nota privada**, e o atendente decide se vai responder. O teste confirmou a nota interna sem disparar mensagem pública; isso ainda não significa ter um atendimento autônomo pronto.

Mais agentes nem sempre significam menos trabalho. Procuro definir o resultado, testar o caminho mais curto e complicar a arquitetura somente quando aparece um motivo concreto.
